# GreenLens Dashboard 产品功能需求 v2

> 状态：Approved for implementation
> 来源：2026-07-29 至 2026-07-30 旧会话中的用户需求、视觉反馈与桌面端范围决策
> 适用页面：`/dashboard`
> 验收优先级：Desktop only

## 1. 产品目标

Dashboard 面向 ESG 研究员和合规分析师，单一任务是：

> 在一个桌面视口内完成样本状态确认、风险扫描、重点公司定位，并进入证据复核。

风险只代表待复核研究信号，不构成对企业漂绿的确定性判断。所有数据继续使用合成内容。

## 2. 用户需求转译

| 用户原始诉求 | 标准产品需求 |
| --- | --- |
| 3D 空间感、实时 AI、动态数据流、电影级光影 | 风险星图作为唯一空间化主视觉；GreenLens Copilot 保留实时上下文；动效只用于数据加载、筛选和层级转换 |
| 只保留蓝色英文标题，整体上移 | 删除 Dashboard 内重复中文标题；英文观测站标识进入唯一顶部控制行 |
| 蓝色页面改为绿色主题，同时保留光影 | 页面背景为近黑中性色；工作面板、数据网格和主数据光使用黑绿体系；红、琥珀、蓝灰继续承担风险语义 |
| KPI 和模块小字太多 | 默认态只显示定义性标签、主体名称、关键数值和主要图形；统计口径、解释、版本等进入详情层 |
| KPI 数字放大约一半 | KPI 数字建立 36–40px 桌面层级；构造指标数字建立 28–32px 层级 |
| KPI 可点详情，其余模块可放大全貌 | KPI 点击打开定义详情；六个分析模块统一提供右上角完整视图入口 |
| 底部三个模块文字被挤压 | 底部保持三栏，但明确列宽、最小字号和图表边距；红旗与质量模块获得更宽列 |
| 背景深黑绿色与面板对比不足 | 页面背景压到近黑，只保留极弱绿色环境光；绿色密度集中在面板与数据层 |
| 所有顶部字段与标题、绿镜同一行 | 英文标题、四组筛选、契约版本、数据状态、导出和绿镜必须处于同一控制行 |
| 不滚动即可看到全部模块 | `1440×900`、`1280×800` 必须无页面级滚动且全部模块完整可见 |
| 热力图色块太暗 | 使用高明度科学色阶，并为单元格增加清晰边界；低值使用蓝灰，不用绿色同时表达低风险 |
| 文字太小，整体放大 | 建立最小 12px、正文 13–14px、模块标题 17–18px 的桌面文字层级；不通过浏览器缩放或整体 transform 放大 |
| 只做桌面网页 | 新增设计与验收只针对 Desktop；既有窄屏代码只做兼容性回归 |
| 不考虑最低成本，以最优结果为导向 | 视觉与交互质量优先，允许调整布局系统、组件契约和自动化门槛 |

## 3. 功能需求

### FR-01 单行控制台

顶部只有一个 Dashboard 控制行，顺序为：

```text
英文观测站标识 | 报告年 | 行业 | 风险 | 样本口径
| 数据契约 | 数据状态 | 导出快照 | 唤醒绿镜
```

验收：

- `1280px` 及以上不得换行。
- 所有控件完整显示，不允许裁切文字或只保留不可识别图标。
- 所有交互控件有可访问名称和可见键盘焦点。

### FR-02 连续单屏布局

页面固定为四个连续信息层，不允许插入空白 Spacer：

```text
┌──────────────────────────────────────────────┐
│ 单行控制台                                   │
├──────────────────────────────────────────────┤
│ 六项 KPI                                     │
├────────────┬───────────────────┬─────────────┤
│ 三方面指标 │ 风险星图          │ 高风险公司  │
├────────────┴───────────────────┴─────────────┤
│ 十年趋势       │ 行业热力      │ 红旗与质量  │
└──────────────────────────────────────────────┘
```

验收：

- KPI 与主分析区之间间距不超过 12px。
- 主分析区与底部分析区之间间距不超过 12px。
- `1280×800`、`1440×900`：无纵向滚动、无模块裁切。
- `1920×1080`、`2048×1227`：主分析区高度设上限，禁止因 `1fr` 无限拉伸产生巨型空白卡片或中部空洞。
- 大屏剩余空间只能出现在全部模块之后，不得出现在 KPI 与主分析区之间。

### FR-03 KPI

- 六项 KPI 保留：当前样本、高风险、三年持续高风险、E-AA 中位数、证据不足、质量提醒。
- 默认态不显示解释性小字。
- 每项可点击打开定义、口径、当前筛选和趋势详情。
- KPI 数字不得因视口变宽而缩小。

### FR-04 主分析模块

- 左：三方面构造指标。
- 中：漂绿风险星图，作为页面唯一视觉签名。
- 右：持续高风险公司。
- 三栏顶部和底部对齐。
- 内容不足时模块保持结构，但不得用大面积无信息留白模拟“高级感”。

### FR-05 底部模块

- 十年风险趋势、行业风险热力、红旗与数据质量保持三栏同行。
- 行业热力必须使用明亮可辨的五级色带。
- 图表坐标、图例和模块文字正常态不低于 12px。
- 红旗条、质量数字和标签不得相互挤压或截断。

### FR-06 详情与完整视图

- KPI 点击打开 KPI 详情。
- 六个非 KPI 模块统一显示右上角完整视图按钮。
- 完整视图必须重新计算图表尺寸，禁止截图放大。
- `Esc` 或关闭按钮关闭后，焦点回到原触发按钮。

### FR-07 GreenLens Copilot

- 顶部“唤醒绿镜”或 `Ctrl/Cmd + J` 打开。
- 保留公司、年度、指标、风险与证据上下文。
- 输出包含结论、指标影响、证据引用、不确定性和下一步复核动作。
- AI 使用紫色通道，不与风险或环境主题绿色混用。

## 4. 视觉规范

### 4.1 色彩

| 角色 | Token |
| --- | --- |
| 页面近黑 | `#010302` |
| 面板黑绿 | `#07170D` |
| 数据绿色 | `#3BDC83` |
| 观测站蓝青 | `#45CFE2` |
| 风险琥珀 | `#F0BD4F` |
| 高风险珊瑚 | `#FF765F` |
| AI 紫色 | `#A982FF` |

页面不使用大面积绿色背景。绿色集中在面板边界、数据线、选中态和已就绪状态。

### 4.2 字体

- 中文正文：`Noto Sans SC Variable`。
- 英文观测站标识：`Space Grotesk Variable`。
- 数字与契约：`IBM Plex Mono`。
- 最小可见文字：12px。
- 筛选/正文：13–14px。
- 模块标题：17–18px。
- KPI：36–40px。

### 4.3 动效

- 首屏入场总时长不超过 500ms。
- 不允许因 stagger 延迟形成“页面加载后仍大面积空白”的观感。
- 环境光极弱；不增加漂浮粒子、装饰球或无业务意义 HUD。

## 5. 非功能需求

- Repository、Zod 数据契约和现有业务路由不得因视觉重构回退。
- 生产构建、Lint、TypeScript、Unit Test 和 Playwright 全部通过。
- Axe serious/critical 为 0。
- 页面 Console 无错误。
- ECharts Canvas 非空。
- 3D 不可用、低内存或 reduced motion 时保留完整 2D 工作流。

## 6. 发布验收矩阵

| 视口 | 必须满足 |
| --- | --- |
| `1280×800` | 单行控制台、全部模块完整、无滚动、无裁切 |
| `1440×900` | 单行控制台、主分析信息密度均衡、底部三栏完整 |
| `1920×1080` | 模块连续排列，主分析区不无限拉伸 |
| `2048×1227` | KPI 后立即出现主分析区，不得重现中部巨幅空白 |

发布阻断：

- 顶部字段换行或裁切。
- KPI 与主分析区之间出现超过 12px 的非业务空白。
- 任一模块超出视口或必须滚动才能看到。
- 正常态可见文字小于 12px。
- 热力图在默认亮度下无法辨认色阶。
- serious/critical 无障碍错误。
